# Security Policy

## Supported versions

Only the latest released version of CopyIT receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, report privately via [GitHub Security Advisories](https://github.com/PinnLabs/CopyIT/security/advisories/new), or email castroofelipee19@gmail.com.

Include:
- A description of the vulnerability and its impact.
- Steps to reproduce.
- Affected version(s).

We'll acknowledge receipt within a few days and keep you updated as we investigate and fix the issue.
